# Comparación de soluciones analíticas y numéricas

En este proyecto se resuelve la ecuación diferencial dy/dt = -k y usando:

- El método de separación de variables (solución analítica).
- El método numérico de Euler.

La comparación se realiza en el intervalo [0,1] con paso h = 0.2.
Se muestra una tabla de valores, el error y una gráfica comparativa.
